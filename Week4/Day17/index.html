    How it's built

    Every reaction and every lab button is wired up once, when the page loads — no handler is created or attached inside a loop that runs on every click. The Reaction Bar uses addEventListener exclusively, since it needs to support being clicked any number of times. The Button Lab deliberately spreads across different techniques — the .onclick property, multiple stacked listeners, the event object, and a self-removing listener — so each one is demonstrated on its own rather than blended together.
