Layout Notes

The header uses position: fixed to stay pinned to the top of the viewport. The sidebar uses position: sticky so it tracks scrolling within the content shell without leaving the layout flow. The content column uses display: flex at the shell level and display: grid for the stat cards, keeping everything aligned without relying on floats.
