    How it's built

    The math lives in a separate CalcEngine object with no knowledge of the page at all — it just takes numbers and an operator and returns a result (or null on a divide-by-zero, which the interface turns into a friendly "Error" instead of letting the app break). A separate UI layer reads button presses and keystrokes and feeds them to the engine.
