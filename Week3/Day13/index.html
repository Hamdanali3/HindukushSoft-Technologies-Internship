Greeting Generator

Type a name, and a function builds the message

Try It

Enter a name and click "Greet Me" (or press Enter).

Your greeting will appear here.

What this does

Clicking the button calls createGreeting(name), a function that takes the name you typed as a parameter and returns a complete greeting sentence — it doesn't touch the page directly. A separate function, displayGreeting(), takes that returned string and writes it into the page.
